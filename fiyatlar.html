Sıkça Sorulan Sorular

Ücretsiz planda hangi araçlar var?

Ücretsiz planda Bilimsel Hakem İncelemesi aracını ayda 3 kez kullanabilirsiniz. Diğer üç araç (Editöryal, Yanıt Asistanı, Checklist) Akademik ve üst planlarda aktiftir.

İstediğim zaman iptal edebilir miyim?

Evet. Profil sayfanızdan abonelik bilgilerinizi yönetebilir, istediğiniz zaman iptal edebilirsiniz. İptal sonrası mevcut fatura döneminin sonuna kadar erişiminiz devam eder.

Anthropic API anahtarı zorunlu mu?

Şu anki beta sürecinde her kullanıcının kendi Anthropic API anahtarını profil sayfasından eklemesi gerekiyor. Production sürümünde bu ihtiyaç kalkacak; ücretler abonelik içinde olacak.

Makale verilerim nerede saklanıyor?

Makale içeriği 30 gün içinde otomatik silinir. Anthropic Claude altyapısını DPA (Data Processing Agreement) altında kullanırız — verileriniz model eğitiminde kullanılmaz.

Kurumsal planda neler farklı?

Kurum geneli erişim, API entegrasyonu, JournalKit ile veri akışı, atanmış destek temsilcisi ve özel onboarding. Teklif almak için bize yazın.

Akademik öğrencilere indirim var mı?

Lisansüstü öğrenciler için %40 öğrenci indirimi mevcut. .edu uzantılı e-posta veya öğrenci belgesi ile başvurabilirsiniz: info@presubly.com

Henüz denemediniz mi?

İlk üç analiz tamamen ücretsiz. Kredi kartı gerekmez, hesap silindiğinde tüm veriler kalıcı silinir.
